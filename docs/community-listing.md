# Community listing submission

Repository: https://github.com/stallinger-dev/obsidian-bases-excerpts

Plugin ID: `bases-excerpts`

Name: **Bases Excerpts**

Suggested listing description:

> Display the first content line beneath a chosen heading as a Bases formula value, with rendered Markdown and source-relative links. Configure headings directly in formulas; no settings needed.

The public listing excerpt is supplied by the repository README. No separate website or changes to the official registry repository are required for the current submission process.

## Submission steps

1. Sign in at https://community.obsidian.md using your Obsidian account.
2. Connect your GitHub account so ownership of the public repository can be verified. If needed, set up the stallinger-dev organization in the directory.
3. Under Plugins, choose New plugin, enter the repository URL above, and select the desired personal or organization owner.
4. Review the developer policies and personally confirm the ongoing support commitment before submitting.
5. Address automated review feedback. The plugin becomes installable through Obsidian only after review errors are resolved.

Official instructions: https://docs.obsidian.md/plugins/releasing/submit-plugin and https://docs.obsidian.md/community-directory/set-up-and-claim.

Before submission: the signed `0.1.0` release must be published with `main.js`, `manifest.json`, and `styles.css`. The repository is public. Undocumented Bases APIs and untested mobile compatibility are disclosed in the README.
